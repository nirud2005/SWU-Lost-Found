# 🎒 Smart Lost & Found – ของหายได้คืน มศว

เว็บแอปประกาศของหาย/เก็บของได้ สำหรับนิสิตมหาวิทยาลัยศรีนครินทรวิโรฒ
ไฟล์เดียว ไม่ต้องติดตั้งอะไร เปิด `index.html` ก็ใช้งานได้ทันที

## ฟีเจอร์
- 🔍 ค้นหาและกรองรายการ (ทั้งหมด / ของหาย / เก็บได้)
- ➕ โพสต์ประกาศพร้อมแนบรูป (ย่อรูปอัตโนมัติ)
- ✨ จับคู่รายการที่อาจตรงกันให้อัตโนมัติ
- 📍 แนะนำจุดนัดรับที่ปลอดภัย
- 🌗 รองรับโหมดมืด/สว่าง และใช้งานบนมือถือ

## วิธีใช้งาน
```bash
git clone https://github.com/<your-username>/swu-lost-found.git
cd swu-lost-found
# เปิด index.html ในเบราว์เซอร์ได้เลย
```

## เผยแพร่ด้วย GitHub Pages
1. ไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<your-username>.github.io/swu-lost-found/`

## ข้อจำกัดปัจจุบัน
ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ จึงเห็นเฉพาะในเครื่องตัวเอง

## เปิดระบบฐานข้อมูล (ให้ทุกคนเห็นประกาศร่วมกัน)
ค่าเริ่มต้นเว็บเก็บข้อมูลในเบราว์เซอร์ของแต่ละเครื่อง ถ้าต้องการให้ประกาศของคนหนึ่งคนอื่นเห็นด้วย ให้ใช้ [Supabase](https://supabase.com) (ฟรี)

1. สร้างโปรเจกต์ใหม่ที่ supabase.com
2. ไปที่ **SQL Editor** วางเนื้อหาไฟล์ `supabase-setup.sql` แล้วกด **Run**
3. ไปที่ **Authentication → Providers → Email** ปิด **Confirm email** (ถ้าต้องการให้สมัครแล้วใช้ได้ทันที)
4. ไปที่ **Project Settings → API** คัดลอก **Project URL** และ **anon public key**
5. เปิด `index.html` ค้นหาบรรทัด `const SB_URL='',SB_KEY='';` แล้วใส่ค่าสองตัวนั้น เช่น `const SB_URL='https://xxxx.supabase.co',SB_KEY='eyJ...';`
6. อัปโหลดไฟล์ขึ้น GitHub ทับของเดิม

หมายเหตุ: anon key เปิดเผยในโค้ดได้ตามการออกแบบของ Supabase ความปลอดภัยอยู่ที่นโยบาย RLS ในไฟล์ SQL ช่องทางติดต่อที่ผู้ประกาศกรอกจะมองเห็นได้โดยทุกคน ข้อความแชทยังเก็บในเครื่องเท่านั้น
